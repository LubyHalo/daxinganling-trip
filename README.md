# 大兴安岭 9 日自驾 · 离线行程助手

2026-09-19 ~ 09-27 的旅行助手。手机浏览器打开一次、加到主屏幕，之后**断网也能查行程、打卡、写手记**。

设计文档见 [`docs/superpowers/specs/2026-09-18-daxinganling-trip-pwa-design.md`](docs/superpowers/specs/2026-09-18-daxinganling-trip-pwa-design.md)。

## 怎么用

1. **装一次**：手机浏览器（iOS 用 Safari，Android 用 Chrome）打开线上地址 → 分享菜单 → 「添加到主屏幕」。必须在有网时完成这一步。
2. **路上**：点图标打开。三个页签——今天 / 行程 / 手记。
   - 点位右侧的「打卡」按钮一键打卡，会记下实际时间。
   - 点某一行打开操作面板：跳过这个点、推迟到明天、改时间/备注/名称、在这里记手记。
   - **跳过和推迟默认只影响你自己的手机**，不会同步给别人；面板里的"通知同伴"开关可以改成共享。
3. **取车 / 还车**：9.19 15:30 与 9.27 15:30 都在哈尔滨太平机场服务点（神州租车）。当天打开应用会显示倒计时；9.27 还会给出「归程时刻表」——按 `还车时间 − 车程 − 缓冲` 倒推出**11:30 前从齐齐哈尔出发**（估算值，以实时导航为准）。
4. **每晚同步**（关键，因为它决定同伴能不能看到你的内容）：
   右上角 ⇄ → 「导出文件」或「复制同步码」→ 发到微信群；
   收到别人的 → 粘进「导入」文本框或选文件 → 显示「新增 X 条 · 更新 Y 条」。

## 三条铁律

- **导入永远不会删掉你本机的内容**，只会新增和更新。所以手滑导错文件什么也不会发生。
- **删除是软删除**，否则删除传不到别人手机上。
- **同一件事在所有手机上算出同一个 id**（如 `check:d1-s1`），所以不需要匹配就能合并。

## 数据在哪

| 内容 | 位置 | 说明 |
|---|---|---|
| 行程内容（路线/景点/住宿/美食/情报） | `data/trip.json`（打包进应用） | 电脑端维护，重新部署后所有人刷新即可 |
| 你的打卡/手记/修改 | 手机浏览器 localStorage | **不上传任何服务器；换手机或清缓存会丢** |

## 开发

```bash
node tests/core.test.mjs      # 核心逻辑单元测试（合并、同步码、日期）
node --test tests/            # 同上，需要能 spawn 子进程的环境
node tools/make-icons.mjs     # 重新生成 PWA 图标
npx serve .                   # 本地预览（Service Worker 需要 https 或 localhost）
```

代码结构：

- `app/core.js` —— 记录模型、合并算法、同步码编解码、日期工具（纯逻辑，有测试）
- `app/store.js` —— localStorage 持久化
- `app/render.js` —— 纯渲染函数（输入视图模型，输出 HTML）
- `app/ui.js` —— 状态、事件、同步流程、撤销
- `sw.js` —— 离线缓存（stale-while-revalidate）
